# 📊 Customer Behavior Analysis

## 📌 Project Overview

Customer Behavior Analysis is an end-to-end Data Analytics project focused on analyzing customer purchasing patterns, preferences, and trends.

In this project, Python is used for data cleaning, preprocessing, and Exploratory Data Analysis (EDA). SQL is used to perform database queries and extract meaningful insights, while Power BI is used to create an interactive dashboard for data visualization and business reporting.

The main objective of this project is to understand customer behavior, identify important trends, and generate meaningful business insights to support better decision-making.

## 📂 Dataset

The project uses a customer behavior dataset containing information about customer activities and purchasing patterns.

The dataset is used to:

* Understand customer purchasing behavior.
* Analyze customer preferences.
* Identify trends and patterns.
* Explore relationships between different variables.
* Generate business insights.

* Python:Data analysis and preprocessing.

## 🔄 Project Steps

### 1. Data Loading

* Imported the dataset into Python.
* Examined dataset structure, shape, and data types.

### 2. Data Cleaning

* Checked for missing values.
* Identified and handled duplicate records.
* Corrected data types.
* Checked data consistency.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

* Performed univariate and bivariate analysis.
* Analyzed customer purchasing patterns.
* Identified trends and relationships.
* Used statistical methods to understand the dataset.
* Created visualizations using Matplotlib and Seaborn.

### 4. SQL Analysis

* Connected Python with PostgreSQL/MySQL.
* Imported the dataset into the database.
* Executed SQL queries to analyze customer data.
* Used SELECT, WHERE, GROUP BY, ORDER BY, JOIN, and aggregate functions.
* Extracted meaningful insights from the database.

### 5. Power BI Dashboard

* Connected the dataset to Power BI.
* Created interactive charts and visualizations.
* Developed KPI cards.
* Added filters and slicers.
* Presented important business insights through an interactive dashboard.
